# sentiment-analysis-using-deep-learning
Sentiment analysis and prediction of sentences by using deep learning. Project demonstrates a fullstack analytics pipeline from ingestion and processing of millions of records to realtime prediction through interactive dashboards.

An end-to-end data engineering, analytics, and deep learning system for large-scale social media sentiment analysis, combining **Spark**, **Deep Learning (GRU)**, **FastAPI**, **R (EDA + Shiny)**, and **Parquet-based analytics**.

This project demonstrates a full-stack analytics pipeline — from ingestion and processing of millions of records to real-time inference and interactive dashboards.
.
.
.
The system is designed to:

- Ingest and process large-scale social media data using Apache Spark
- Perform feature engineering and aggregation, storing outputs in Parquet
- Train and deploy a GRU-based sentiment analysis model
- Serve predictions via a FastAPI-based inference service
- Perform exploratory data analysis (EDA) using R
- Visualize analytics and predictions using an interactive R Shiny dashboard
- Expose EDA plots and reports via API endpoints for reuse by any frontend
